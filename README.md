# Shopee Thailand Data Analysis

Exploratory data analysis on Shopee Thailand datasets.

## Dataset
https://www.kaggle.com/datasets/hninshwezinhlaing/shopee-th-customer-journey-and-operations-dataset

## Project Objectives
- Analyze customer behavior
- Explore sales trends
- Identify business insights
- Visualize e-commerce data

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Structure
data/        -> datasets  
notebooks/   -> analysis notebooks  
visuals/     -> charts and dashboards
